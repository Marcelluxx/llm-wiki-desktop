# LLM Wiki Desktop 0.9.0

Release Windows con supporto completo per installazioni portabili e miglioramenti di compatibilità.

## Novità della versione 0.9.0

- **Esecuzione modulare OpenDataLoader:** Risolto il problema di avvio del worker su macchine portatili/pulite eliminando i percorsi assoluti dei wrapper e avviando i moduli direttamente tramite l'interprete locale.
- **Ambiente isolato e PATH privato:** Configurazione esplicita di `PYTHONHOME`, pulizia di `PYTHONPATH` ed estensione del timeout di handshake a 30s per garantire la massima resilienza anche su CPU meno veloci o al primo avvio.
- **Librerie di sistema MSVC incluse:** Raggruppate tutte le DLL C/C++ Microsoft Visual C++ necessarie per l'OCR e il parsing offline.
- **Chat Wiki integrata:** Interfaccia di chat migliorata con rendering Markdown avanzato, streaming risposte e navigazione note.

## Download

Scarica esclusivamente **LLM-Wiki-Setup.exe** dagli asset di questa Release. I file
automatici **Source code (zip)** e **Source code (tar.gz)** contengono il codice
sorgente e non sono l'applicazione installabile.

## Incluso

- applicazione Windows x64 e disinstallazione standard;
- runtime Python e Java privati, usati solamente da LLM Wiki Desktop;
- estrazione locale PDF, DOCX, TXT e Markdown;
- OpenDataLoader PDF con OCR locale per i documenti scansionati;
- wiki multiple, cache SHA-256, chat e ingest tramite provider AI;
- integrazioni Codex, Claude Code, Antigravity, OpenRouter e Ollama.

## Nota sulla firma Windows

Se questa Release non è ancora firmata digitalmente, Microsoft Defender SmartScreen
può mostrare un avviso per un'app poco conosciuta. Verifica sempre che il download
provenga da `github.com/Marcelluxx/llm-wiki-desktop` e confronta il checksum con
`SHA256SUMS.txt` prima di avviare il setup.
